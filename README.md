# Priyadharshika Palanivelu — Personal Portfolio

A responsive, no-build personal portfolio showcasing AI engineering, full-stack development, technical leadership and selected product work.

## Website

Intended URL after publishing: **https://priyadharshika13.github.io/**

## Publish with GitHub Pages

1. Sign in to GitHub as `priyadharshika13`.
2. Create a **public** repository named exactly `priyadharshika13.github.io` at https://github.com/new (do not initialize with any other website files).
3. Extract this ZIP file and upload `index.html`, `assets/`, `.nojekyll`, and `README.md` to the **root** of the repository; commit to `main`.
4. Go to **Settings → Pages → Build and deployment**. Select **Deploy from a branch**, **main**, and **/(root)**. Save.
5. Open `https://priyadharshika13.github.io/` after GitHub Pages has published the site.

**Note:** The site is not published merely by downloading the ZIP. You must create the repository and upload the files to your own GitHub account.

## Edit your portfolio

- `index.html`: content, sections, projects, links, SEO.
- `assets/styles.css`: visual design, colors, layout, responsive design.
- `assets/app.js`: navigation, theme switching, filters and reveal animations.
- `assets/favicon.svg`: monogram favicon.

## Add a personal photo

The portfolio currently loads your GitHub profile avatar. To substitute a particular photograph:

1. Save your cropped portrait as `assets/profile.jpg`.
2. In `index.html`, replace the `img src` in the `.portrait-wrap` element with `./assets/profile.jpg`.
3. Change the `og:image` URL to a publicly accessible full URL if desired.

## Built with

Plain HTML, CSS and JavaScript. No Node, npm, backend, or database required. Works with GitHub Pages and on local static hosting.
